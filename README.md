# Anil Kumar Singh - Smart Interactive Resume

This repository contains the source code for an interactive, "smart" web resume, designed specifically to showcase executive-level civil engineering leadership and massive infrastructure achievements.

## 🚀 Features
- **Premium Dark Mode UI:** Built with sleek glassmorphism panels and modern typography (Inter).
- **Micro-Animations:** Smooth scroll-reveal animations using an Intersection Observer.
- **Data-Driven Impact:** Highlights monetary values and project scales (e.g., ₹13,300 Crore Yamuna Expressway, 390 MW Dulhasti Hydroelectric Project).
- **Responsive:** Fully responsive grid/flex layout for flawless viewing on mobile devices.

## 🌐 How to Host on GitHub Pages (Free)

You can publish this resume live on the internet in under 3 minutes using GitHub Pages!

### Step 1: Create a GitHub Repository
1. Go to [github.com](https://github.com) and log in.
2. Click the `+` icon in the top right and select **New repository**.
3. Name your repository (e.g., `anil-resume` or `aniketrajsingh.github.io`).
4. **Description (optional):** Paste this: `Executive Web Portfolio & Smart Resume of Anil Kumar Singh — Specializing in massive road infrastructure projects.`
5. Keep it **Public**.
6. Click **Create repository**.

### Step 2: Upload Files
1. In your newly created repository, click **"uploading an existing file"**.
2. Drag and drop the `index.html` file from this folder into your browser.
3. Click the green **Commit changes** button at the bottom.

### Step 3: Activate GitHub Pages
1. Go to the **Settings** tab of your repository.
2. In the left-hand sidebar under "Code and automation," click **Pages**.
3. Under "Build and deployment" -> "Source", select **Deploy from a branch**.
4. Right below that, under "Branch", change `none` to `main` (or `master`) and keep the folder as `/ (root)`. 
5. Click **Save**.

### 🌍 You're Live!
Wait about 1 to 2 minutes, refresh the page, and at the top of the GitHub Pages settings screen, you will see a link that says:
> **"Your site is live at https://[your-username].github.io/[repo-name]/"**

Copy that link—you can now put it in your LinkedIn bio or email signature!
